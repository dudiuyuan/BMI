# A 同学数据准备：方法、代码与交接解释

## 1. 目标和边界

本项目要比较时间序列距离与聚类方法。真实 GEO 数据没有完整可靠的“每个基因属于哪一簇”的答案，所以主要的客观恢复能力测试必须使用**先给类别、后生成观测**的模拟数据。老师对 proposal 的反馈特别要求说明模拟数据怎样产生，以及各变化怎样服务于 benchmark。本设计把生成规则、标签、扰动、清洗、数据版本和接口逐项写明。

A 的代码只准备输入和核验其正确性：**没有实现 B 的 DTW、C 的聚类、D 的指标、E 的生物学验证**。这样算法性能不会被输入生成器的“自我评价”混淆。核心 Python 代码由本组按以下公式编写，没有调用现成的时间序列生成器；外部来源仅用于真实数据和生物背景。

## 2. 文件如何协作

1. `simulation.py` 接收配置和 seed，产出 `expression.csv`、`ground_truth.csv`、`gene_parameters.csv`、`metadata.json`。表达矩阵不含标签或模板参数；这是防止标签泄漏的接口边界。
2. `preprocessing.py` 只读取表达 CSV。它检查时间列和 ID，按缺失阈值删行、插值、输出三种数值版本，并记录每行决策。它不导入也不读取 `ground_truth.csv`。
3. `generate_sweep.py` 按预设实验表调用以上两个模块，输出 100 套数据和索引。D 可以逐套取数据再做 B/C 算法比较。
4. `prepare_real_data.py` 从 GEO 文件的 `!Sample_*` 和 `!series_matrix_table_begin` 部分提取真实矩阵，独立导出 GSE3635 和 GSE4987 的每组时间序列，并使用相同预处理器。
5. `audit_gpr.py` 读取已有 GSE3635 GenePix 压缩文件，仅检查 spot 层级源文件与 GEO 样本对应，不把 spot 行误作基因。
6. `make_figures.py` 读模板定义、模拟输出和 GEO 样本统计，生成 SVG。`build_all.py` 用固定配置串起这些步骤；`tests/` 检查真实交付物。

## 3. 六类模拟曲线的精确定义

对第 \(g\) 个基因，第 \(i\) 个时间点设 \(u_i=i/(T-1)\)，实际分钟数为 \(D u_i\)（默认 \(D=120\)）。先赋予类别 \(z_g\)，再计算

\[
x_{gi}=b_g + a_g f_{z_g}(\tau_{gi};w_g)+\sigma\epsilon_{gi},\qquad
\tau_{gi}=\operatorname{clip}(u_i^{\gamma_g}-\delta_g,0,1).
\]

其中 \(\epsilon_{gi}\sim N(0,1)\) 是固定 seed 下预先抽取的测量误差；\(b_g\sim U(-0.1,0.1)\) 是基线；峰宽 \(w_g\sim U(0.075,0.095)\)。模板输出无单位，模拟表达值是任意单位，不与 GEO log ratio 数值直接相加或比较。

| 标签 | 模板 \(f_z(u)\) | 为什么选它 |
| --- | --- | --- |
| `early_peak` | \(\exp[-(u-0.20)^2/(2w_g^2)]\) | 早期局部峰。 |
| `late_peak` | \(\exp[-(u-0.78)^2/(2w_g^2)]\) | 与早峰形状相同但时间不同，可测试 DTW 是否抹去相位。 |
| `oscillatory` | \(\sin(4\pi u)\) | 两个周期的升降，代表重复振荡型。 |
| `transient_induction` | \(s((u-0.39)/0.025)s((0.64-u)/0.025)\)，\(s(q)=1/(1+e^{-q})\) | 中间短暂上调并形成宽平台，与单尖峰不同。 |
| `transient_repression` | 上一函数的负值 | 中间短暂下调。 |
| `flat_noise` | \(0\) | 无动态信号；在测量噪声为零时可能成为常值。 |

模板图见 `figures/six_templates.svg`。图是函数本身在 0–120 分钟的 2 分钟网格上的绘制；正式模拟可使用任意 \(T\ge3\)，默认 13 点。每类 `genes_per_class` 条基因，ID 如 `SIM_early_peak_0001`，总数为 `6 × genes_per_class`。基因 ID 和类别不随 seed 及扰动强度重新洗牌，便于配对。

## 4. 五种扰动与实验目的

| 参数 | 实际生成规则 | 四级 sweep | 希望观察的问题 |
| --- | --- | --- | --- |
| `noise_sd` | \(\sigma\epsilon_{gi}\)，独立标准正态；数值是任意表达单位 | 0, 0.05, 0.12, 0.25 | 测量误差提高时，各距离对簇的恢复如何变化？ |
| `max_shift` | \(\delta_g=m q_g,\ q_g\sim U(-1,1)\)；\(m\) 是总时长比例 | 0, 0.03, 0.08, 0.16 | 时间错峰时，DTW 的对齐优势与早/晚峰合并风险如何平衡？ |
| `amplitude_sd` | \(a_g=\exp(s_a z_g),\ z_g\sim N(0,1)\) | 0, 0.15, 0.35, 0.60 | 幅度差异影响距离吗？逐基因 z-score 是否抹掉这个挑战？ |
| `missing_rate` | 每个观测点独立抽 \(v_{gi}\sim U(0,1)\)，若 \(v_{gi}<p\) 就写空白 | 0, 0.08, 0.16, 0.31 | 插值与删行在缺测增多时对恢复率及样本数的影响？ |
| `stretch_sd` | \(\gamma_g=\exp(s_t z'_g)\)，\(\tau=u^{\gamma_g}-\delta_g\) 为单调时间变换 | 0, 0.08, 0.20, 0.40 | 局部进程快慢不同时，DTW 是否更稳健？ |

`amplitude_sd` 和 `stretch_sd` 都是**自然对数尺度**参数；每个基因实际的 \(a_g,\delta_g,\gamma_g\) 记在 `gene_parameters.csv`。给定 seed、gene_id 和随机数流名称，程序用 SHA-256 派生独立流：形态、扰动、测量误差、缺失各有自己的流。这样同一 seed、同一基因在四个强度下保留相同潜在抽样；例如改变缺失比例时，高比例遮蔽会包含低比例遮蔽，未遮蔽的数值完全相同。改变噪声强度不会重新抽幅度或位移。`sweep_index.csv` 的 SHA-256 可防止后续文件静默变动。

每个 sweep **只改变一项**；其余固定为噪声 0.05、位移上限 0.03、幅度 log SD 0.15、缺失 0、伸缩 log SD 0.08。五因素 × 四级 × seed 3100–3104 = 100 套。全部每类 25 条、13 点，故每套清洗前 150 行。D 应在同一套 `centered.csv` 上只改变距离方法，记录 ARI/NMI/运行时间；跨 seed 报告分布或均值与方差。挑 DTW window 的开发 seed 不能用于最后评估。`challenge` 同时加重五因素，仅用于暴露接口或困难案例，**不能拿它冒充单因素受控结果**。

## 5. 真标签的两个定义

- **主任务 `true_cluster`：六类、相位敏感。**早峰与晚峰分开，适合研究表达时间本身有意义的情况。模拟 benchmark 可设 \(k=6\)，但这不意味着真实 GEO 必然有六个簇。
- **补充任务 `shape_cluster`：五类、形状敏感。**只把早峰和晚峰映射到 `broad_peak`，其余四类保持原标签。两类标签都在 `ground_truth.csv`，不在给算法的表达 CSV。两种任务的 ARI 不应混为同一个分数。

由于合并了两个原本等大的类别，五类任务的 `broad_peak` 有其他单类两倍的基因数；D 解读指标时需注明这一预设类不平衡，而不是把它当成随机采样误差。

这种双标签设计直接处理潜在冲突：若无限制 DTW 把早峰和晚峰成功对齐，它在形状问题中可能正确，在相位问题中可能错误。高噪声或强位移会造成类别重叠，标签仍按生成前的指定类别保留；这不是数据错误，而是要测出的困难程度。

## 6. 预处理规则及其理由

输入必须是唯一非空 `gene_id`，后接严格递增的 `t数字` 列；至少三个时间点。非有限数值直接报错，空白/`NA`/`null` 可作为缺失。对每行：

1. 缺失比例 **大于** 0.4 或全缺失时删除。13 点中缺 5 点为 38.5% 可保留，缺 6 点为 46.2% 会删除。不同强度可能使保留行数不同；D 必须报告行数并按 ID 连接真标签。
2. 内部缺口按**实际时间坐标**线性插值；两端缺口用最近观测值填充。所有距离方法使用同一批插补后的行，避免将 NaN 送入普通 DTW。
3. `raw_imputed.csv` 保留输入尺度；`centered.csv` 每条轨迹减自身均值，消去随意基线但保留幅度差；`zscore.csv` 再除以该行的总体标准差，用于独立的形状分析。三者行顺序相同。
4. 若标准差小于 \(10^{-12}\)，z-score 行输出全 0，日志计数。Pearson 对常值行在数学上未定义；建议 C 统一规定“双常值距离 0、单常值与非常值距离 1”，并在实现中标注该约定。不能仅为 Pearson 临时删行而让 DTW/Euclidean 使用不同输入。

清洗器不读取 `ground_truth.csv`，但真实数据的 ORF 控制筛选属于清洗器**之前**的来源处理。`row_log.csv` 对每行写 `kept`、`too_missing` 或 `all_missing`；`preprocessing_log.json` 写输入行数、保留行数、插补单元格及时间列。若改变阈值，应另存版本和日志，避免与既有指标混用。

## 7. 两份真实数据如何处理

源文件是 GEO series matrix，样本标题与 `!Sample_geo_accession` 决定列的时间和 GSM；**不用文件列位置猜测时间**。两个原件 SHA-256 都在各自 `data_preview_summary.json`。`sample_manifest.csv` 为每个 GSM 给出时间、有效/缺失数、均值、中位数、总体 SD、范围；`data_preview.csv` 仅保留前五行明确预览。`feature_decisions.csv` 保存每个原始 `ID_REF` 的保留/排除结果。

筛选规则：把 ID 转大写，然后只保留符合 `Y[A-P][LR][三位数字][C/W]` 且可选 `-字母` 后缀的酵母核基因 ORF；因此 `YER060w-A` 规范化为 `YER060W-A`。空白/外源控制与不规范 ID 被排除，共 13 行。没有偷偷按轨迹形状或 Spellman 名单筛基因；后续如果 E 获取更正式的平台 ID 映射，应在新版本中保留对照表，不覆盖本文件。

GSE3635：13 个 GSM，0–120 分钟每 10 分钟；6,228 特征、172 个空值，ORF 行 6,215，40% 缺失阈值后 6,214 行，165 个值插补。GEO 概述说明无生物学重复。另存的 13 个 GPR 文件每个是 7,056 条 spot 行，包含重复 spot；`gpr_audit.json` 只做来源/QC 记录，**不能直接与已处理矩阵的 6,228 行或模拟值拼接**。

GSE4987：50 个 GSM，依标题的时间重置拆成 `run01` 与 `run02`，各 0–120 分钟、5 分钟间隔、25 点。6,228 特征共 440 个空值；筛 ORF 后两组分别插补 352、87 个值，均保留 6,215 行。GEO 说明有 dye-swap 技术重复，但系列矩阵在这里保留两组各自轨迹；没有预先配对平均，也没有当成 50 点单条轨迹。

两者在 [GSE3635 官方记录](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE3635) 和 [GSE4987 官方记录](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE4987) 中都属于 GPL1914 微阵列。其 `VALUE` 在 GEO 元数据中描述为 Rosetta Resolver 的 normalized log ratio；这里没有把它解释成 RNA-seq counts，也没有在没有核准底数、批次和重复处理规则前合并两个研究。E 的生物学验证应使用独立参考集合，不把模拟标签赋给真实基因。

## 8. 交接时的最低可复核检查

- 从 `outputs/simulated/smoke/processed/centered.csv` 读入，能够得到 12 行、7 点、全有限数值；聚类后再按 ID 关联相应真标签。
- 改 `--genes-per-class`、`--timepoints`、`--seed` 可重新生成；同一配置/seed 的四个模拟文件字节一致，不同 seed 的表达数据变化。
- `sweep_index.csv` 有 100 行，每个目录的 expression 与 centered 文件校验和一致；每次 benchmark 记录 `factor,level,seed`。
- 比较 Euclidean、Pearson、DTW 时，使用同一套预处理矩阵和相同 gene_id 顺序；主分析用 centered，z-score 另列实验。
- 报告模拟任务的主/次标签定义及被过滤行数；真实数据只作聚类解释与外部注释验证。

## 9. 已知限制和后续分工

解析模板缺少真实调控网络、基因间相关噪声、异方差与非随机缺失；flat 类的幅度缩放不会改变零模板；强扰动导致类间重叠，模拟分数不可能代表真实生物学准确率。GSE3635 无生物学重复，GSE4987 的实验批次与 dye-swap 处理需要 E 进一步核对。当前没有 probe-to-gene 一对多汇总，因为 GEO 处理表 `ID_REF` 已唯一且可直接按 ORF 筛选；未来换平台时需要新规则。B/C/D/E 应在自己的模块文档中补齐算法版本、参数选择、运行环境、真实输出和解释。
